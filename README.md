# Gatehouse

> Nothing harmful gets past the gate.

Autonomous fraud-defense agent for households. Screens every risky inbound signal,
investigates it like an expert analyst, escalates only real decisions to the
family guardian. Built on the Strands Agents SDK, deployed on Amazon Bedrock
AgentCore.

Status: design phase, document control active. See docs/.
