## 1. Philosophy

Unmeasured agents are toys. Every claim in the pitch traces to a number this
harness produces, seeded and reproducible, with limitations published beside it.
Sentinel discipline carries over: fixed seeds, held-out splits, byte-identical
metrics across runs, and honest disclosure where baselines beat us.

## 2. Dataset Design

### 2.1 Adversarial benchmark set (the headline metric source)

Composition target v1: 600 cases.

| Stratum | Count | Examples |
|---|---|---|
| KYC/bank expiry scams (en, hi) | 90 | "SBI KYC expires today" + fresh-domain link |
| Digital arrest / authority impersonation | 60 | police/CBI/ED scripts, Skype/WhatsApp moves |
| Investment / trading group invites | 70 | WhatsApp group screenshots, crypto pump scripts |
| UPI collect request fraud | 60 | mule VPA screenshots, wrong-person-payment reversal scams |
| Lottery/prize/KBC | 40 | classic advance-fee |
| Courier/customs/package | 40 | DHL/FedEx impersonation with payment link |
| Job/task scams | 40 | prepaid task, Telegram recruitment |
| OTP/impersonation-of-relative | 40 | "papa need money urgent" AI-voice-note transcripts |
| Legitimate-but-scary (false-gate traps) | 80 | real bank offers, genuine govt notices, delivery updates with links |
| Benign noise | 80 | newsletters, family chatter, OTP forwards by users themselves |

Sourcing rules: scripts synthesized from public pattern libraries (GASA scam
types, I4C advisories, pack lexicons), paraphrased at multiple literacy levels and
both languages, URLs use reserved-example domains plus a private test zone (no live
registration of lookalike domains, ever). Every case carries ground truth labels:
verdict, intent tags, expected action, language, difficulty tier.

Split discipline: 480 dev/calibration, 120 sealed hold-out generated by the same
generator with a different seed, never opened during development. Hold-out opens
exactly twice before submission: once mid-build sanity check (P4 exit), once final
(P6). Runs against hold-out log their seed and prompt versions.

### 2.2 Longitudinal soak set (production honesty)

The builder's own households generate real traffic during P5-P7. Weekly report
publishes: volume, verdict distribution, guardian agreement rate, false-gate
reports, latency, cost. This becomes the launch trust page and the strongest
possible demo material ("here is my father's actual week").

## 3. Metrics Definitions (exact formulas)

| Metric | Definition | v1 bar |
|---|---|---|
| Precision (SCAM) | TP / (TP + FP) on SCAM verdicts vs ground truth | >= 0.90 |
| Recall (SCAM) | TP / (TP + FN) | >= 0.85 |
| False-gate rate | legitimate cases escalated as DECISION needing human / all legitimate | <= 0.05 |
| Noise leak rate | NOISE-classified items later flagged scam by any means / all noise | <= 0.02 |
| Escalation precision | escalations where guardian agreed action was warranted / escalations | tracked, no hard bar v1 |
| Latency p50/p95 | forward timestamp to notification sent | <= 8s / <= 30s |
| Cost per investigation | USD per case, mean and p95 | <= $0.02 mean |
| Degraded-mode share | cases completing with any degraded flag | reported honestly, target < 10% |
| Engagement lift | verdict confidence delta with vs without engage on gray-band subset | measured, informs default settings |

Confusion reporting includes per-stratum breakdown; aggregate numbers alone hide
exactly the failures that matter (for example false gates concentrated in the
legitimate-bank-offer stratum).

## 4. Regression Gates (CI)

PR-level (fast, offline): schema validation of all agent outputs, deterministic
checks suite, prompt-lint (fencing intact, canaries present, length budgets),
rule classifier accuracy floor on a frozen mini-set.

Nightly: 200-case replay against staging AgentCore endpoint with mock external
intel, full metrics computed, diff against last green run. Any metric dropping
beyond tolerance (precision -0.02, false-gate +0.01, cost +20%) fails the build
and blocks merge until triaged. Prompt version bumps require nightly green before
deploy.

Release gate (P6): full 600-case run including sealed hold-out, all tables
published into README plus docs/eval-results/, failure taxonomy appendix written
from actual misclassified cases (no invented humility, no hidden failures).

## 5. Failure Taxonomy (required appendix format)

Every hold-out miss gets classified: missed_pattern_family, language_gap,
verification_tool_gap, threshold_miscalibration, orchestration_bug,
degraded_mode_cause, labeling_dispute. Counts per class go in results. This turns
failures into the v1.1 roadmap instead of shame, and it is precisely the maturity
signal senior judges screen for.

## 6. Statistical Honesty Rules

- Report Wilson 95% CIs on proportions (Sentinel precedent).
- McNemar's paired test when comparing system variants on the same set
  (TruthLayer precedent).
- No tuning on hold-out, ever. Threshold changes justified only on dev split,
  then re-run hold-out once and report both pre/post transparently.
- Seed, model IDs, pack versions, prompt versions embedded in metrics.json so any
  number regenerates byte-identical.

## 7. Eval Harness Components (build list for P2/P3)

```
evaluation/
  generator/        case synthesizers per stratum (seeded, typed templates)
  runner/           replays cases through investigator (staging endpoint or local)
  scorers/          metric computation, Wilson CIs, per-stratum tables
  regression/       tolerance checks vs baseline metrics.json
  reports/          markdown + json artifacts committed under docs/eval-results/
  chaos/            dependency kill switches for degradation-matrix assertions
```

Runner modes: LOCAL_MOCK (no AWS, mocked tools), STAGING (real models, synthetic
intel), PRODUCTION_SHADOW (live traffic copy, no notifications). Chaos mode wraps
any runner with dependency fault injection matching the doc 03 failure matrix.

## 8. Acceptance Criteria for This Document

1. Harness reproduces every published number from one command with pinned inputs.
2. All nine metrics computable in CI without manual steps.
3. Failure taxonomy populated from real hold-out misses at release gate.
4. Soak-set weekly report automated by P6.
